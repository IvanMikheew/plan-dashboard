# tools/avito_stats.ps1 — сбор статистики Авито (Business API) в CSV

Назначение: посуточная статистика объявления (показы, просмотры, контакты) через
официальное Avito API (`api.avito.ru`), дописывание строк в дневник замеров CSV.

## Запуск

```powershell
powershell -ExecutionPolicy Bypass -File tools\avito_stats.ps1 -DateFrom 2026-11-15 -DateTo 2026-11-24
powershell -ExecutionPolicy Bypass -File tools\avito_stats.ps1 -DateFrom 2026-11-25 -DateTo 2026-11-30 -ItemId 8547421312
```

Параметры: `-DateFrom`, `-DateTo` (обязательные, `yyyy-MM-dd`), `-ItemId`
(по умолчанию 8547421312), `-EnvPath`, `-CsvPath`, `-RawDir`, `-NoCsv`
(только скачать сырьё, CSV не трогать). Повторный запуск безопасен:
строки `дата+объявление_id`, уже есть в CSV, не дублируются.

## Зависимости

Windows PowerShell 5.1+ (или pwsh), доступ в интернет. Ничего устанавливать не нужно.

## Переменные окружения (только имена)

Файл `.env` (путь задаётся `-EnvPath`, по умолчанию `C:\Users\user\Desktop\opencode\.env`):
`AVITO_CLIENT_ID`, `AVITO_CLIENT_SECRET`. Значения скрипт читает сам при запуске,
никогда не печатает и не пишет в файлы. Держать `.env` вне git.

## Что делает (эндпоинты Avito Business API)

1. `POST /token` — авторизация client_credentials.
2. `GET /core/v1/accounts/self` — user_id аккаунта (сохраняется только id, без email/телефона).
3. `POST /stats/v2/accounts/{user_id}/items` — метрики по дням (grouping=day)
   и по объявлениям (grouping=item): impressions, views, contacts и др.
   Rate limit: 1 запрос/мин — скрипт ждёт и повторяет при HTTP 429.
4. `POST /stats/v1/accounts/{user_id}/items` — посуточные счётчики по объявлению
   (uniqViews, uniqContacts, uniqFavorites) — кросс-проверка.
5. `POST /core/v1/accounts/{user_id}/calls/stats/` — статистика звонков.

Сырые ответы (JSON) сохраняются в `отчёты\avito-api-raw\`.

## CSV

Файл `отчёты\статистика-авито.csv`, схема:
`дата,объявление_id,показы,просмотры,контакты,записи,источник`

- показы = `impressions` (показы в поиске/рекомендациях, уникальные по юзеру/сутки);
- просмотры = `views` (совпадает с v1 `uniqViews`);
- контакты = `contacts` (посмотрели телефон + написали в чат, уникальные по юзеру/сутки);
- записи — пустая колонка (офлайн-данные), источник — `avito-api`.

Метрики v2 считаются на весь профиль аккаунта. Если в периоде активно более одного
объявления, скрипт пишет просмотры/контакты из v1 (по объявлениям), а показы
оставляет пустыми (API не отдаёт показы в разрезе объявления).

## Ограничения API (проверено по спеке и прогоном)

- Глубина данных: 270 дней; v2: не более 1000 сущностей в ответе.
- «Долистали до конца», источники просмотров, поисковые запросы — API не отдаёт
  (нет методов), есть только в личном кабинете Авито.
- Звонки: `calls/stats` отдаёт данные только по звонкам через Авито (calltracking).
