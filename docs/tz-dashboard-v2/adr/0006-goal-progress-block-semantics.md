# 0006. Блок «Успеваемость к цели»: окно = активный период с нормировкой цели, «Всё время» = окно цели

- **Статус:** принято
- **Дата:** 2026-11-26
- **Контекст:** цель «+475 показов за 2 недели» определена на 14-дневное окно, но блок по
  требованию владельца «подчиняется фильтру периода» (SPEC R5). Противоречие: у «Всё время»
  и произвольного диапазона нет «2-недельной» длины; при этом дефолтный экран обязан
  показывать картину владельца (темп 103/нед против нужных 237,5/нед).
- **Варианты:**
  1. **Нормировка цели на окно фильтра:** цель_окна = 475 × длина_окна/14, темп =
     Σпросмотров_окна × 7/длина_окна, прогноз = темп × 2, вердикт = прогноз ≥ 475;
     спец-случай: «Всё время» = окно цели `[anchor−13..anchor]`. Плюсы — блок живёт в
     контексте фильтра, вердикт всегда «за 2 недели» к цели; минусы — дробные цели окна
     (237,5), одна неочевидная спец-ветка для «Всё время».
  2. Блок всегда в фиксированном 14-дневном окне, фильтр игнорируется: плюс — просто;
     минус — прямо противоречит требованию «подчиняется фильтру».
  3. Цель достигнута накоплением от старта («сколько набрали с момента постановки цели»):
     минус — нет даты постановки цели, прогноз «через 2 недели» не определён.
- **Решение:** вариант 1. Прогноз всегда «при текущем темпе через 2 недели будет N»,
  N = темп × 2 (простая линейная экстраполяция недельного темпа — прозрачна владельцу;
  альтернатива «среднее по всему окну» искажается старыми данными). Вердикт: N ≥ 475 →
  зелёный «Успеваем», иначе красный «Не успеваем». <2 дней данных → «нет данных».
- **Последствия:** цель — константой `GOAL = {views: 475, days: 14}` в одном месте
  (меняем числа, не логику); смена цели/периода цели в UI или хранилище — отдельным
  решением позже (YAGNI). При смене владельцем длины цели пересчитывается только конфиг.
  Минус: «Всё время» для этого блока ≠ «всё данные» — зафиксировано осознанно (иначе
  дефолтный экран не показывает целевую картину).
- **Связи:** SPECIFICATION.md R5, §6.7; TASKS.md TASK-6; ADR-0001 (селекторы окон),
  ADR-0002 (state.range/applyRange); файлы: `avito.html` (секция `goal`, `render`).
